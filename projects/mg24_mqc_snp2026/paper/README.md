# SNP2026 manuscript

`main.tex` is the concise contributory-paper manuscript for the 70th DAE
Symposium on Nuclear Physics (SNP2026). It uses the official PdfLaTeX
contributory-paper class distributed by the symposium website. The copied
template files are preserved beside the manuscript because the official class
is not part of a standard TeX Live installation.

Compile only in WSL from the repository root:

```bash
cd /mnt/d/Coding/sky3d
cd projects/mg24_mqc_snp2026/paper
mkdir -p build output/pdf
"/mnt/c/Program Files/MiKTeX/miktex/bin/x64/pdflatex.exe" \
  -interaction=nonstopmode -halt-on-error -synctex=1 \
  -output-directory="D:\\Coding\\sky3d\\projects\\mg24_mqc_snp2026\\paper\\build" \
  "D:\\Coding\\sky3d\\projects\\mg24_mqc_snp2026\\paper\\main.tex"
"/mnt/c/Program Files/MiKTeX/miktex/bin/x64/pdflatex.exe" \
  -interaction=nonstopmode -halt-on-error -synctex=1 \
  -output-directory="D:\\Coding\\sky3d\\projects\\mg24_mqc_snp2026\\paper\\build" \
  "D:\\Coding\\sky3d\\projects\\mg24_mqc_snp2026\\paper\\main.tex"

install -m 0644 \
  build/main.pdf output/pdf/mg24_mqc_snp2026.pdf
```

The absolute Windows paths prevent a WSL-interop MiKTeX process from inheriting
the repository root as its working directory. The compiler is still launched
only from WSL.

The two included figures are regenerated by
`../scripts/make_publication_figures.py`; do not edit them manually.
Bibliographic titles, journals, volumes, article/page numbers, years, and DOIs
in `references.bib` and the camera-ready bibliography were checked against the
publisher records and Crossref on 2026-08-29.
